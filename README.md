\# Tablero de cartera de seguros



Dashboard desarrollado en Streamlit para el análisis de cartera y cotización de seguros.



\## Funcionalidades



\- Filtros por cobertura, sexo, uso, combustible y edad.

\- KPIs de exposición, siniestros, frecuencia, severidad y prima pura.

\- Gráficas de frecuencia y rentabilidad.

\- Cotizador empírico, GLM y prima de tarifa.



\## Ejecución local



Instalar dependencias:



pip install -r requirements.txt



Ejecutar la aplicación:



streamlit run app\_streamlit\_deploy.py
